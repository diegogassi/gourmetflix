
PENDIENTES

✅ Funcionalidades necesarias para la v1.0

Usabilidad
- Restricción de acceso a libros para usuarios sin membresía activa.
- Ocultar los botones de secciones que no están habilitadas para usuarios comunes (Administración)
- Página de membresía (/membresia) con información sobre el plan y futuro pago automatizado.
- mostrar los últimos libros accedidos en la Home y en Catálogo, para que sea más simple retomar la lectura desde donde estaba antes de irse
- Modo offline (PWA) para guardar libros localmente.

Usuarios y acceso
- Google Login para permitir autenticación con cuenta de Google.
- Restablecimiento de contraseña olvidada.
- Verificación de email después del registro (para evitar registros falsos).
- Página de perfil de usuario (/perfil) para modificar datos personales, email y contraseña
- Opción de cambiar la dirección de email en /perfil
- Corregir en /registro que da error cuando se intenta registrar un mail que ya estaba registrado anteriormente
- da error cuando se ingresa un password incorrecto en el login

Membresías
- Fecha de expiración de membresía
- Implementación de Stripe o MercadoPago para pagar y activar membresías automáticamente.

Diseño y UX
- Header en todas las páginas con un pequeño logo y un menú de navegación.
- Mejoras en la UX/UI de todas las páginas, incluyendo estilos, botones, y experiencia del lector de EPUB.
- Implementar "Loading states" para la espera entre pantallas
- Implementar Errores globales y opcionalmente un log de errores






✅ Funcionalidades para la v2.0

Diseño y UX
- Buscador de libros por título/autor
- Modo nocturno y ajuste de tamaño de letra en el lector.
- Optimización de la navegación en libros (botones para pasar página, índice de contenido).
- Opción para "Ir a la página X"
- Índice de capítulos en el lector para una navegación más fluida.
- Lista de deseos para marcar libros que el usuario quiere leer más adelante.
- Calificaciones y comentarios en libros.

- Compartir libros en redes sociales.

- Mostrar progreso de lectura en el catálogo o ficha del libro - "Última lectura: 45%"


Membresías y usuarios
- Notificaciones internas (por ejemplo, si vence la membresía en 7 días).

Admin
- Dashboard de Admin con estadísticas básicas (usuarios activos, libros más leídos).
